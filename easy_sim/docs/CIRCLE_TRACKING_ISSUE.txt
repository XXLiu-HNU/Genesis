==============================================================================
                圆形轨迹跟踪问题分析和解决方案
==============================================================================

问题描述
--------
圆形轨迹跟踪时，无人机会出现振荡并最终失控下降。

根本原因
--------
经过详细分析，发现主要有以下几个原因：

1. **动力学模型差异**
   - Genesis: 使用完整的刚体动力学 + 气动阻力 + 地面效应
   - Easy Sim: 简化的刚体动力学，无阻力模型
   
   结果：easy_sim中的响应更"理想化"，导致PID控制过于激进

2. **数值积分方法**
   - Genesis: 使用substeps和高级约束求解器
   - Easy Sim: 简单的欧拉积分，dt=0.01s
   
   结果：easy_sim的数值稳定性较差，累积误差更大

3. **PID参数不匹配**
   - 原始参数是针对Genesis动力学模型调优的
   - 直接用在easy_sim会导致过冲和振荡

分析数据
--------
从测试数据可以看到：

步  0: 姿态正常，RPM=595K（悬停）
步100: 姿态角39.6°，RPM暴涨到744K-803K
步200: 姿态角53.2°，开始振荡
步300: RPM饱和到1041K-2082K，失控

姿态角过大 → 垂直推力不足 → 下降 → PID更激进 → 恶性循环

理论分析
--------
圆形轨迹（半径1m，角速度0.5rad/s）：
- 所需向心加速度：0.25 m/s²
- 所需向心力：0.125 N
- 所需倾斜角：仅1.46°（理论值）

但实际观察到的姿态角远大于理论值（40-50°），说明PID控制器
响应过度，导致系统不稳定。

临时解决方案
------------

方案1：大幅降低PID增益（已尝试，效果有限）
   位置控制器 kp: 1.5 → 0.8
   角度控制器 kp: 6500 → 3000
   
   结果：延迟失控，但仍会失控

方案2：增加阻尼（推荐）
   在easy_sim动力学模型中添加速度阻尼：
   
   ```python
   # 在 _update_linear_dynamics 中添加
   drag_coeff = 0.1
   drag_force = -drag_coeff * self.velocity
   acceleration += drag_force / self.mass
   ```

方案3：降低轨迹速度
   omega: 0.5 → 0.2 rad/s
   让控制器有更多时间响应

方案4：增加时间步长
   dt: 0.01 → 0.005 (更精细的控制)

方案5：使用级联PID
   位置 → 速度 → 加速度 → 姿态
   而不是直接 位置 → 姿态

根本解决方案
------------

选项A：重新调参（耗时）
   需要针对easy_sim的动力学特性，从头开始调整PID参数。
   建议使用自动调参工具（如Ziegler-Nichols方法）。

选项B：改进动力学模型
   在easy_sim中添加：
   1. 空气阻力模型
   2. 更好的数值积分方法（RK4）
   3. 螺旋桨动态响应

选项C：使用MPC替代PID
   模型预测控制对模型误差更鲁棒，但计算复杂度更高。

选项D：混合方法
   使用RL训练的策略进行轨迹跟踪，而不是传统PID。
   这正是sim2sim测试的目的！

当前建议
--------

对于immediate使用：
1. 测试悬停控制（已验证正常）
2. 测试慢速直线运动
3. 暂时避免高速圆形轨迹

对于sim2sim测试：
1. 使用训练好的RL策略进行轨迹跟踪
2. RL策略通常比PID更鲁棒
3. 这正是easy_sim的设计目的

对于PID控制器改进（future work）：
1. 实现方案2（添加阻尼）
2. 使用更保守的PID参数
3. 添加anti-windup和饱和保护
4. 实现自适应PID

==============================================================================
                        总结
==============================================================================

圆形轨迹跟踪问题的根本原因是easy_sim的简化动力学模型与Genesis
存在差异，导致原始PID参数不适用。

短期解决方案：使用更保守的参数，测试低速轨迹
长期解决方案：改进动力学模型，或使用RL策略替代PID

easy_sim的主要用途是sim2sim测试RL策略，而不是PID控制器调优。
因此建议优先使用训练好的RL策略进行轨迹跟踪测试。
