使用示例
--------

1. 基本悬停控制:

from controller import Odom, PIDController, load_pid_config
from drone_dynamics_sim import QuadrotorDynamics
import numpy as np

sim = QuadrotorDynamics({'dt': 0.01})
sim.reset(position=[0, 0, 1.0])

odom = Odom(num_envs=1)
odom.set_sim(sim)

config = load_pid_config()
controller = PIDController(1, odom, config, "position")

for step in range(1000):
    target = np.array([[0.0, 0.0, 1.0, 0.0]])
    motor_rpms = controller.step(target)
    state = sim.step_rpm(motor_rpms[0])


2. 圆形轨迹跟踪:

python test_circle_tracking.py --radius 1.0 --steps 1500


关键参数
--------
- base_rpm: 595000 (基于物理计算的悬停RPM)
- thrust_compensate: 1.0
- 位置控制器 kp: [1.5, 1.5, 1.0]
- 姿态控制器 kp: [6500, 6500, 7000]

技术特点
--------
1. 完全独立: 不依赖Genesis，纯NumPy/SciPy实现
2. 模块化设计: 仿真器、控制器、状态估计器分离
3. 易于集成: 简洁的API，清晰的接口
4. 可扩展: 支持批量环境，易于添加新控制器

已知限制
--------
1. 圆形轨迹跟踪存在高度下降问题
   - 原因: PID参数可能需要针对easy_sim优化
   - 解决方案: 调整位置控制器增益或混控器逻辑

2. 批量环境控制器未充分测试
   - 当前重点在单环境
   - 批量版本的接口已实现但需要更多验证

3. 仅支持X型四旋翼布局
   - 当前实现针对target_drone_urdf
   - 其他布局需要修改混控器
